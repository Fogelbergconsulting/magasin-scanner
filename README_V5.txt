Magasin Scanner v5 – filmunderlag. Ny flik 3D-mätning för val av order, lokal filmimport, sex provrutor, manuell checklista, anteckningar och export av mätunderlag. Ingen automatisk täckningsanalys, fotogrammetri eller volymberäkning. Originalfilm lagras inte i appen. Mätunderlag sparas separat i webbläsarens localStorage och synkas inte till Supabase. Befintlig v4-data och synkronisering lämnas oförändrade. Publicera samtliga filer i ZIP på GitHub Pages. Ta säkerhetskopia före uppdatering.
