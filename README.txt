MAGASIN SCANNER – WEBBAPP FÖR IPHONE 14

Detta är en körbar prototyp med manuellt inmatade höjder i ett 3×3-rutnät.
Den gör INTE automatisk 3D-rekonstruktion av video eller fotografier.

PROVA PÅ WINDOWS
Dubbelklicka index.html och öppna i Chrome eller Edge. Skriv in mått och
höjder. Klicka Beräkna volym och Skapa PDF-rapport.

INSTALLERA PÅ IPHONE
1. Publicera hela katalogen som en statisk HTTPS-webbplats, t.ex. på GitHub Pages.
2. Öppna webbplatsens HTTPS-adress i Safari på din iPhone.
3. Tryck Dela -> Lägg till på hemskärmen -> Öppna som webbapp -> Lägg till.
4. Öppna ikonen Magasin Scanner.

DATA
Mätningar sparas lokalt i webbläsaren. Säkerhetskopiera genom JSON-export.
Bilder ingår i aktuell rapport, men inte i den lokalt sparade historiken.
PDF skapas via webbläsarens utskriftsfunktion.

NÄSTA TEKNISKA STEG
Kamerabaserad 3D-rekonstruktion kräver separat fotogrammetrimotor/server,
referenskalibrering, 3D-mesh och kvalitetssäkring mot verkliga referensmätningar.
